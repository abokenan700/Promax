## AUDIT SCOPE

For every issue found, record:
```
ID: [P1-###]
File: [path] — Line: [ref if available]

Problem: [precise description]

```

### 1.1 — Spacing & Layout
Detect: broken 4/8px rhythm, inconsistent container widths,
RTL margin/padding inversions (margin-left used instead of margin-inline-start),
invalid or arbitrary Tailwind class usage.

### 1.2 — Typography
Detect: missing visual hierarchy, hardcoded font sizes outside the scale,
insufficient Arabic line-height (minimum 1.6 for Arabic body text),
contrast ratios below WCAG AA (4.5:1 text, 3:1 large text).

### 1.3 — Component Consistency
Audit every instance of: button, card, input, OTP input, sheet, dialog,
badge, navbar, footer, skeleton, carousel, toast, tooltip, empty state, error state.
Detect: inconsistent radius or shadow, missing interaction states
(hover / active / focus / disabled), design token violations (hardcoded colors or spacing).

### 1.4 — Motion & Interaction
Detect: janky or abrupt transitions, inconsistent easing curves,
incorrect RTL slide direction (sheets and drawers must enter from the LEFT in RTL),
missing feedback on user actions, layout-triggering animations (use transform/opacity only).

### 1.5 — Mobile Ergonomics
Detect: primary CTAs outside the bottom thumb zone on mobile,
touch targets below 44×44px, content overflowing viewport edges,
broken or inconsistent responsive breakpoints.

### 1.6 — Conversion UX
Detect: weak or buried CTA hierarchy, missing trust signals on key pages,
excessive cognitive load (too many competing elements),
blank or generic empty states, unhelpful error states.
