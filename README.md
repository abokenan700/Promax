# Promax Project - Professional Architecture

هذا المشروع تم إعادة هيكلته وتنظيفه بشكل احترافي لضمان أفضل أداء وسهولة في الصيانة.

## بنية المشروع (Architecture)

المشروع يتبع نمط **Monorepo** المنظم:

- **apps/**: يحتوي على التطبيقات الأساسية.
  - `vibe-app`: التطبيق الرئيسي (Frontend).
  - `api-server`: خادم الواجهة البرمجية (Backend).
  - `mockup-sandbox`: بيئة تجريبية للتصاميم.
- **packages/**: يحتوي على المكتبات المشتركة وقواعد البيانات.
  - `db`: إعدادات وقواعد بيانات Drizzle.
  - `api-spec`: مواصفات OpenAPI.
  - `api-client-react`: عميل API المولد لـ React.
  - `api-zod`: مخططات التحقق Zod.
- **scripts/**: سكربتات الأتمتة والصيانة.

## التحسينات التي تمت:
1. حذف كافة الملفات المكررة والمكدسة.
2. إزالة ملفات التقارير والأصول غير الضرورية (`audit-reports`, `attached_assets`).
3. توحيد المسارات وتحديث التكوينات (`tsconfig`, `package.json`).
4. تنظيم الملفات في مجلدات دلالية (`apps` و `packages`).
